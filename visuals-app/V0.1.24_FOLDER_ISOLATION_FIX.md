# v0.1.24 Folder Isolation / Freeze Fix

This candidate is intentionally narrow. It does not redesign Stage/Visual transforms, masks, overlays, presets, or GREEN/production behavior.

## Root causes found in v0.1.23 source

1. `scan_layer_media` was a synchronous Tauri command that directly ran `ffprobe` and, for HEVC/MOV sources, `ffmpeg`. Changing a folder could therefore block GTK/WebKit long enough for Linux to report the app as not responding.
2. Runtime routes were layer-scoped (`layer-<layer-id>-0001`) and mutable. Duplicated layers initially inherited another layer's transient library/route IDs, creating avoidable coupling between otherwise independent media layers.
3. `changeLayerFolder()` refreshed the changed layer and then rebuilt the entire Visual Workspace. That destroys/recreates every `<video>` element, forcing unrelated layers to reload at the same time.
4. `duplicateLayer()` cloned the source layer's transient media library, including route IDs. A duplicate should copy editor state, not transient runtime bindings.

## Fixes in this candidate

- `scan_layer_media` now runs blocking probing/conversion in `spawn_blocking`, keeping the GUI event loop responsive.
- Media route IDs and compatibility runtimes are keyed by physical source fingerprint, not layer ID.
- Conversion cache moved to `media-cache/by-source`, so duplicated layers reuse the same prepared source instead of re-encoding by layer.
- Compatibility conversion preset changed from `medium` to `veryfast` for workstation runtime preparation. Original files are never modified.
- Folder refresh updates only the affected layer's catalog/inspector/source; it no longer rebuilds the whole workspace/canvas.
- Startup background catalog completion also updates the existing workspace instead of destroying/recreating all videos.
- Duplicating a layer no longer inherits transient library route bindings; the duplicate registers its own catalog.
- Normal folder refresh preserves the selected source by path when possible. Folder change intentionally selects index 0 only for the changed layer.

## Required regression test

Create two generic media layers A and B. Both may initially point to Visuals.

- Change only A to Stage folder.
- B's `sourceFolder`, `mediaIndex`, selected filename, route URL and current playback must not change.
- A may show PREPARING while HEVC is converted, but the app must stay responsive.
- Change A back to Visuals. B must still be untouched.
- Repeat five times.

The transform and mask architecture is deliberately unchanged.
