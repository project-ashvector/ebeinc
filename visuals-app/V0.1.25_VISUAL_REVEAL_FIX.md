# v0.1.25 Visual Reveal / Explicit Stage Role Fix

## Root cause found from the v0.1.24 screenshot

The normal Visual layer is not failing to decode. The live status shows both media layers are PLAYING:

- the upper duplicated media layer is playing `alpha.mov`
- the lower Visual Content layer is playing a normal visual MP4

The visual is hidden because the `alpha.mov` compatibility runtime is H.264 and therefore has an opaque black center where the source's transparent screen was. The duplicated Stage-folder layer currently has `MEDIA MASK: NONE`, so that black center physically covers the correctly playing Visual layer beneath it.

This is an occlusion/compositing issue, not a media-loading or transform issue.

## v0.1.25 changes

- Adds explicit media-layer roles: Normal Media, Visual Content, Stage Overlay.
- Stage Overlay is an explicit user-controlled role; changing folders never silently changes role, mask, frame, fit, or transform.
- Marking a layer as Stage Overlay explicitly enables the existing Stage Screen mask and puts it above Visual Content if needed.
- Changing away from Stage role explicitly clears the Stage Screen mask.
- Adds a one-time migration for the exact current legacy layout: one Visual Content duplicate pointed at the Stage folder above the normal Visual layer becomes `Stage Content`, role `stage`, mask `stage-screen`.
- Adds an inspector role selector and a context-menu `Mark as Stage Overlay` / `Mark as Normal Media` action.
- Adds an occlusion warning when a Stage-folder media layer is above Visual Content with no Stage Screen mask.
- Keeps folder changes rendering-neutral.
- Keeps the v0.1.24 source-fingerprint routing/folder-isolation architecture intact.
- Moves the legacy playlist import fully off the first-paint critical path.

## Important architecture rule

A media folder is just a source. A Stage role is a rendering/compositing choice. They are separate.

`Change Media Folder` must never mutate the layer role or mask.

The user can explicitly mark any generic media layer as Stage Overlay when they want its internal screen to reveal the Visual Content beneath it.
