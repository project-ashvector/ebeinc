WHAT IS ALREADY IMPLEMENTED
- The main radio page has a synchronized public feed, now-playing metadata, listener chat, reactions, requests, schedule/history, PWA support, responsive mobile layout, and live DJ takeover support.
- The main page uses a full-screen animated radio background and has Listen, Chat, Schedule, Hosts, and Visuals navigation.
- The Visuals page is intentionally visual-first: it loops radio/assets/radiovisualtab.mp4 full-screen and has a small translucent MAIN PAGE link at the top.
- The Visuals page also has a LISTEN LIVE button. It resolves the current stream URL from https://status.ebeinc.online/api/public/status and lets visitors play/pause the shared live feed. Audio requires a user click because browser autoplay rules require interaction.
- The Visuals live player has interruption recovery: it refreshes the status URL, reconnects after audio error/stall/end/pause events, retries with backoff, and resumes audio/video after network or tab visibility changes. The Visuals audio and main site both use the same public status-derived stream URL.
- The Visuals video is the optimized web version of Downloads/0806.mp4: 1280x720, 30 FPS, silent, about 24.5 MB, with fast-start metadata.
- The main feed connect button now visibly changes to CONNECTING…, disables duplicate clicks, pulses while connecting, and reports connection failures.
- The DJ/server app (latest local package 0.4.26) now shows playable rotation counts separately from total catalog entries. It includes ERASE SELECTED and ERASE CANCELLED / NOT APPROVED actions with confirmation; erased audio is moved to server trash for recovery, and the active on-air track is protected until it leaves the air.
- AutoDJ uses a persistent shuffle bag for approved playable tracks: every track in the current approved set is transmitted once before the bag reshuffles. If the approved set changes, the bag rebuilds safely from the new set.
- The DJ Settings tab includes a rights-unconfirmed TEST MODE switch, default off, with an explicit private-testing/legal warning. When enabled by an administrator, approved/enabled tracks without confirmed rights may enter the shared feed; disabling it immediately returns the rotation to rights-cleared files.
- radio/sw.js cache version is v8. Bump it whenever changing cached shell files.
- The current latest site commit includes the feed-button loading state. The latest visuals/audio deployment should be verified against the production domain after deployment propagation.
