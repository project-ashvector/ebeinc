# Store Asset Checklist

## Already included
- `play-store-assets/icon_512.png` — 512x512 PNG, approximately 537 KB.
- Adaptive/legacy launcher assets are included in the Android project.

## Still create from the FINAL tested build

### Feature graphic
- 1024 x 500 pixels.
- JPEG or 24-bit PNG without alpha is the safest standard format for Play listing artwork.
- Use the ALLTHINGS140 dark/purple/orange visual identity.
- Keep critical text/logo away from extreme edges.
- Do not show UI/features that are not actually present.

Suggested concept: dark live-stage/radio-energy background, large ALLTHINGS140 Radio identity, "24/7 HEAVY BASS RADIO", restrained purple/orange energy elements. Keep it readable at small preview size.

### Phone screenshots
Capture real screenshots from the signed/release-candidate build after UI validation. Suggested set:
1. Native Home / LIVE radio screen.
2. Playing state with real track/artist + listener count.
3. Settings showing Version and Check for Updates.
4. Visuals screen.
5. Optional landscape or larger-device screenshot only if it genuinely looks polished.

At least two screenshots are needed for a publishable store listing; use more if they communicate real value without repetition.

### Screenshot QA
- No debug suffix/version if screenshots represent production.
- No fake listener counts or fake track metadata.
- No personal notifications/status-bar data if avoidable.
- No Green Room screenshot for the initial release.
- Verify text is not clipped at the exact device density used.
