## Short description
24/7 heavy dubstep and bass radio with live station visuals.

## Full description
ALLTHINGS140 Radio is a 24/7 home for heavy bass music, built around dubstep, riddim, tearout, and the underground sounds around them.

Listen from a native Android player designed for continuous radio playback. See what is playing, check the live listener count when station data is available, and keep the stream going while your screen is off or while you move around your phone.

### Built for listening
- Native live-radio playback
- Background and screen-off audio
- Lock-screen and system media controls through Android media sessions
- Bluetooth/headset media-control support
- Android Auto media browsing support
- Automatic recovery logic for interrupted live playback

### Know what is on
The app can show the current song/artist and live listener count using public ALLTHINGS140 station status data when available.

### Station visuals
Open the dedicated ALLTHINGS140 Visuals experience without turning the entire app into a website wrapper. The public station website opens in your normal browser.

### Proper app settings
See the exact installed app version/build, check the station release feed for a newer version when configured, read the in-app privacy notice, or jump to the official station website.

ALLTHINGS140 Radio is built for listeners who want a focused heavy-bass station experience without needing an account to press play.
