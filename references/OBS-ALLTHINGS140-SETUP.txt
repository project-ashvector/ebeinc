OBS AUDIO SOURCE
1. Sources > + > Media Source.
2. Name: AllThings140 Private Radio Feed.
3. Uncheck Local file.
4. Input: paste the private audio URL above.
5. Keep Restart playback when source becomes active enabled.
6. Keep Close file when inactive disabled so scene changes do not tear down
   the network connection.
7. In Advanced Audio Properties, assign the source to streaming track 1.
8. Use Monitor Off for stream-only audio, or Monitor and Output if you also
   need to hear it locally. Do not capture that monitor device again through
   Desktop Audio, or the station will echo.

RELIABILITY CHECKLIST
- OBS Settings > Advanced > Network: enable automatic reconnect with a
  2-second retry delay and at least 25 retries.
- Use wired Ethernet, not Wi-Fi.
- Disable computer sleep and USB/network power saving.
- Keep OBS audio at 48 kHz stereo and AAC 128–160 kbps.
- Use H.264 CBR and a 2-second keyframe interval for the shared Twitch/Kick
  profile. X documents a 3-second interval, so a separate X output profile is
  preferable when your multistream tool supports per-destination settings.
- Avoid sending three full uploads directly if your connection lacks ample
  headroom. One upload to a reliable cloud multistream relay is safer.
- Watch OBS Stats for Dropped Frames (Network). Any sustained non-zero rise is
  an uplink/route problem, not a source-volume problem.
