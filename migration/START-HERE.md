# ALLTHINGS140 migration package

This package rebuilds the management/development environment and documents the Oracle production service. Oracle is the broadcast authority; a workstation is only a secured controller and build machine. The public Cloudflare site and Android clients consume the same continuous Icecast broadcast. Google Drive remains the audio master, with an Oracle hot cache and emergency library.

Start with `NEW-PC-SETUP.md`, then `SECRETS-REQUIRED.md`. Do not copy secrets into source control. A missing workstation must never stop the station.
